## See it in action

### Loli. Listens, answers, plays

<img src="https://raw.githubusercontent.com/zxcloli666/SoundCloud-Desktop/f4e23db0a516ebfca7192938ca8404587c5432dc/readme-9.0/loli-en.webp" width="100%" alt="Loli answers on top of the player" />

"Play Psychosis". "Louder". "Next". "Skip a minute ahead". Hands full, music still does what you say. Or just talk to her: she recommends tracks, answers out loud and remembers what you like.

Four voices: Loli and Moriarty speak English and Russian, Heart and Michael speak English. Speech is recognized on your computer, microphone audio never leaves it. Needs STAR. [How to turn it on](https://docs.getsoundcloud.app/en/use/voice)

<img src="https://raw.githubusercontent.com/zxcloli666/SoundCloud-Desktop/f4e23db0a516ebfca7192938ca8404587c5432dc/readme-9.0/moments-en.webp" width="100%" alt="Moments feed: the best 30 seconds of every track" />

The best 30 seconds of every track in one feed. Scroll, get hooked, hit "Play full track", and it goes on from that very spot. [More](https://docs.getsoundcloud.app/en/use/moments)

### Music videos right in the player

## Why people install it

**400,000+ downloads** on Windows, macOS and Linux. Same music, same account, everything else is better.

| | SoundCloud in a browser | SoundCloud Desktop |
|---|:---:|:---:|
| No ads | no | **yes** |
| Voice assistant | no | **yes**, STAR |
| 10-band equalizer | no | **yes** |
| Synced lyrics | partly | **yes** |
| Library without internet | no | **yes** |
| Listen together, chats | no | **yes** |
| Theme catalog | no | **yes** |
| Tray mini player | no | **yes** |
| Discord status | partly | **yes** |

Compared with a browser on a free account. [Full table](https://getsoundcloud.app/en/compare)

### Inside, free

- **Wave** picks tracks for you: genres, 12 languages, vibe, fresh only
- **HQ sound** with no subscription
- **Lyrics** follow the vocal; none found - search or paste your own
- **Chats and rooms**: listen together and share tracks
- **Offline**: saved tracks play without internet
- **Superlikes**: what you love counts three times in the Wave
- **Playlist import** from Spotify, Yandex Music and VK
- **Themes and wallpapers**: theme catalog, live background, [custom CSS](https://github.com/zxcloli666/SoundCloud-Desktop/blob/main/docs/CUSTOM_CSS.md)
- **System**: media keys, hotkeys, tray mini player, Discord, MPRIS
- **7 languages**: English, Russian, Turkish, Korean, Portuguese, Spanish, French

### STAR

The app is free. STAR is for those who want the maximum: Loli, UQ sound, Go+ tracks, effects (slowed, reverb, 8D, bass), faster servers, unlimited superlikes. [What is inside](https://docs.getsoundcloud.app/en/star)

### Light

Tauri 2 and Rust instead of Electron: the system WebView, and native code does the audio, not a browser.

> Source code and development live in the [main repository](https://github.com/zxcloli666/SoundCloud-Desktop).

## Download

### Windows

Right here or from the [releases page](https://github.com/zxcloli666/SoundCloud-Desktop-EN/releases/latest):
- **[`soundcloud-desktop_x64-setup.exe`](https://github.com/zxcloli666/SoundCloud-Desktop-EN/releases/latest/download/soundcloud-desktop_x64-setup.exe)** - installer, recommended
- **[`soundcloud-desktop_x64_en-US.msi`](https://github.com/zxcloli666/SoundCloud-Desktop-EN/releases/latest/download/soundcloud-desktop_x64_en-US.msi)** - alternative installer
- **[`soundcloud-desktop-portable.exe`](https://github.com/zxcloli666/SoundCloud-Desktop-EN/releases/latest/download/soundcloud-desktop-portable.exe)** - portable, no install

Requirements: Windows 10 (1809+) or Windows 11

File signing: [Code signing policy](https://github.com/zxcloli666/SoundCloud-Desktop#code-signing-policy)

The app needs the Microsoft Edge WebView2 Runtime. The installers (~220 MB) carry it inside and install it without a download, antivirus tools flag such downloads. The portable exe (~43 MB) does not carry it: if WebView2 is missing or Windows is a stripped build, install the [Evergreen Standalone Installer](https://developer.microsoft.com/microsoft-edge/webview2/) as administrator. Edge itself is not needed.

### Linux

| Format | Architecture | Best for |
|--------|-------------|----------|
| `.deb` | amd64, arm64 | Ubuntu, Debian, Mint, Pop!_OS |
| `.rpm` | amd64, arm64 | Fedora, openSUSE, CentOS |
| `.AppImage` | amd64, arm64 | Universal, runs anywhere |
| `.flatpak` | amd64 | Sandboxed |
| AUR `soundcloud-bin` | amd64, arm64 | Arch, Manjaro, EndeavourOS |

Download from the [releases page](https://github.com/zxcloli666/SoundCloud-Desktop-EN/releases/latest) or from the [website](https://getsoundcloud.app/download) if GitHub does not open.

Arch and derivatives: our [`soundcloud-bin`](https://aur.archlinux.org/packages/soundcloud-bin) package is published to the AUR automatically within a minute of every release.
```bash
yay -S soundcloud-bin
```
There is also a community package, [`soundcloud-desktop-bin`](https://aur.archlinux.org/packages/soundcloud-desktop-bin), maintained by someone else. Install only one of the two.

Install the Flatpak from our repository to get updates through `flatpak update` and app centers (GNOME Software, Discover):
```bash
flatpak install --user https://zxcloli666.github.io/SoundCloud-Desktop/flatpak/soundcloud-desktop.flatpakref
```
The downloaded `soundcloud-desktop.flatpak` connects the same repository when installed: `flatpak install --user soundcloud-desktop.flatpak`.

For AppImage:
```bash
chmod +x soundcloud-desktop_*.AppImage
./soundcloud-desktop_*.AppImage
```

### macOS

> [!NOTE]
> **macOS blocking the launch?** The app isn't signed with an Apple Developer certificate, so Gatekeeper might show a "the app is damaged" error. It is easily fixed with one command:
> ```bash
> xattr -cr /Applications/soundcloud-desktop.app
> ```
> After that, the app will launch normally.

## Updating

The app checks for new versions at startup and every six hours. To check manually and see your version, open **Settings -> About -> Updates**.

| Build | How it updates |
|---|---|
| Windows `setup.exe` / `.msi`, macOS `.dmg`, `.AppImage` | "Install and restart" button, settings and cache stay |
| Windows portable | Quit the app from the tray (right-click the icon, then Quit) and replace the exe with the downloaded one |
| `.deb` / `.rpm` | Install the new package over the old one |
| AUR | `yay -Syu soundcloud-bin` |
| Flatpak | `flatpak update` or your app center. Installed an older `.flatpak` and see no updates? Reinstall once with the new file: `flatpak install --user --reinstall soundcloud-desktop.flatpak` (without `--reinstall` it fails with "Directory not empty") |
| Built from source | `git pull` and rebuild |

If you installed a new version but the old one opens, the old one is still running in the tray: quit it with Quit and start the app again.

## Logs

If the app crashes or something does not play, attach `desktop.log` to your bug report. Both the interface and the native part write to it, panics included. Tokens and `session_id` in links are hidden.

The "Open folder" button in **Settings -> About -> Diagnostics** opens the folder. Paths:

| OS | Folder |
|---|---|
| Windows | `%LOCALAPPDATA%\com.soundcloud.desktop\logs` |
| macOS | `~/Library/Logs/com.soundcloud.desktop` |
| Linux | `~/.local/share/com.soundcloud.desktop/logs` |

## Building from Source

<details>
<summary><b>Developer instructions</b></summary>

### Requirements

- **Node.js** 22+
- **pnpm** 10+
- **Rust** 1.99.1, rustup installs it from rust-toolchain.toml

### Run

```bash
git clone https://github.com/zxcloli666/SoundCloud-Desktop.git
cd SoundCloud-Desktop/desktop
pnpm install
pnpm tauri dev
```

### Production build

```bash
pnpm tauri build
```

Artifacts will appear in `src-tauri/target/release/bundle/`.
